Frequently asked questions

How are purchases delivered?

Checkout connects directly to Tebex once your store details are added to the shop config — see "How do I connect Tebex?" below. Until then, this storefront runs as a demo that creates a copyable order summary.

How do I connect Tebex?

In the shop config, add your Tebex public token and a package ID for each product under the Tebex settings near the top, then turn Tebex on. Checkout will automatically switch from the demo order summary to a real Tebex checkout, and the button will tell you if anything's still missing.

How do I change prices?

Open the shop config and edit the products object near the top. The cards, cart, and featured rank price update automatically.

Can I change the server IP?

Yes. Change serverIp in the shop config. The Copy Server IP button will use that value.

Can I add more items?

Yes. Add another product entry with a name, category, price, icon, color class, description, and features.

How do I add discount or partner codes?

Open the shop config and edit shopConfig.promoCodes near the top. Add a discount code with a percentage or fixed amount, or add a partner code with a creator name and discount. For the code to also change what Tebex charges, create a matching Coupon or Creator Code in your Tebex panel too.

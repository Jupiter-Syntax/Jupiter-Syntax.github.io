Frequently asked questions

How are purchases delivered?

This storefront is frontend-only, so you can connect the checkout button to Tebex, Stripe, CraftingStore, your own backend, or another payment provider later.

How do I change prices?

Open script.js and edit the products object near the top. The cards, cart, and featured rank price update automatically.

Can I change the server IP?

Yes. Change serverIp in script.js. The Copy Server IP button will use that value.

Can I add more items?

Yes. Add another product entry with a name, category, price, icon, color class, description, and features.

How do I add discount or partner codes?

Open script.js and edit shopConfig.promoCodes near the top. Add a discount code with a percentage or fixed amount, or add a partner code with a creator name and discount.
